# دورینو (Dorino)

بازی دورهمی فارسی، آفلاین و مستقل، الهام‌گرفته از تجربه‌ی بازی‌های Party Game تک‌گوشی — با پشتیبانی کامل از تعداد بازیکنِ نامحدود (فقط با شرط زوج بودن).

## ویژگی‌ها

- بدون سقف مصنوعی برای تعداد بازیکنان (۴، ۶، ۸، ...، هر عدد زوجی)
- دو حالت بازی: «نبرد دو تیم» و «تیم‌های دونفره»
- الگوریتم کاملاً پویا برای چیدمان دایره‌ای بازیکنان دور میز
- تخصیص خودکار تیم بر اساس فرمول‌های ریاضی ساده (بدون Hardcode)
- پایگاه‌داده‌ی کلمات فارسی در ۱۵ دسته‌بندی
- تایمر قابل تنظیم، سیستم امتیاز و زمان ذخیره‌شده
- افکت صوتی، لرزش و انیمیشن‌های نرم
- طراحی Dark Premium با پشتیبانی کامل RTL
- کاملاً آفلاین — بدون نیاز به اینترنت یا حساب کاربری
- قابلیت ادامه‌ی بازی نیمه‌تمام و تاریخچه‌ی بازی‌ها

## تکنولوژی

- Kotlin + Jetpack Compose + Material 3
- معماری MVVM (data / domain / ui)
- Kotlinx Serialization + DataStore برای ذخیره‌سازی
- Navigation Compose

## ساخت پروژه

```bash
./gradlew assembleDebug
```

فایل APK در مسیر زیر ساخته می‌شود:

```
app/build/outputs/apk/debug/app-debug.apk
```

این پروژه همچنین دارای یک GitHub Actions Workflow (`.github/workflows/build.yml`) است که با هر Push به‌صورت خودکار یک APK دیباگ می‌سازد و آن را به‌عنوان Artifact در تب Actions قابل‌دانلود می‌کند.

## ساختار پروژه

```
app/src/main/java/com/dorino/game/
├── data/        # مدل‌ها، پایگاه کلمات، ذخیره‌سازی، صدا
├── domain/      # منطق خالص بازی (چیدمان، تیم‌بندی، موتور بازی)
└── ui/          # صفحات Compose، ناوبری و کامپوننت‌ها
```
